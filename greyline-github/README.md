# 灰線：邊境檢查官（GREYLINE）

一款可直接在瀏覽器遊玩的原創邊境證件審查敘事遊戲。保留文件查驗、規則遞增、經濟壓力與道德抉擇的玩法類型，但國家、角色、文件、劇本與視覺均為原創，未使用其他遊戲的美術或台詞。

## 遊戲內容

- 15 個值勤日、4 個章節與完整最終抉擇
- 126 位固定種子產生的入境者，每次戰役內容一致且可重玩
- 頂視邊境站、動態排隊人潮、入站／離站與遞件動畫
- 統一實體桌面：文件、對話紙、每日公告與值勤手冊都可拖放及排序
- 收件槽機制：入境者先遞件，玩家再自行把文件拿到工作區
- 8 類文件：護照、入境許可、工作證、疫苗證明、外交通行狀、新聞通行證、安檢申報單與指紋複核單
- 16 項逐步累積的審查規則
- 可比對的對話紀錄、七類追問主題、矛盾盤問與指紋複核
- 大量依人格、目的、文件與說謊狀態產生的對話及回話文本
- 照片核對、通緝名單、簽發城市、官方印章與拘留判定
- 正確／錯誤回執、實體督察罰單、扣薪、賄賂與特殊人物事件
- 每日租金、食物、暖氣、藥品與家人健康系統
- 多個夜間事件與 8 種結局
- 自動存檔、聲音效果、暫停與鍵盤快捷鍵
- 可調整文字大小、工作台縮放、聲音與動畫

## 操作

| 操作 | 方式 |
| --- | --- |
| 整理桌面 | 滑鼠拖動文件、對話紙、公告及手冊；點擊文件置頂 |
| 交互比對 | `Q`，再點擊兩個同類欄位或有資料的對話句子 |
| 追問入境者 | 使用對話紙上方的目的、停留、身分等問題按鈕 |
| 盤問矛盾 | 比對出不一致後，按對話紙上的盤問按鈕 |
| 核准入境 | `A` 或綠色核准章 |
| 拒絕入境 | `D` 或紅色拒絕章 |
| 拘留候審 | 第 9 日起，對通緝犯或違禁品持有人使用拘留按鈕 |
| 桌面手冊 | `R` 翻開／收合；展開時時鐘仍會繼續 |
| 暫停／繼續 | `Esc` |

每位入境者處理薪資為 5 克朗。同一天前兩次錯誤只警告，第三次起每次扣 10 克朗。

## 本機執行

```bash
npm install
npm run dev
```

開啟 Vite 顯示的網址。正式建置：

```bash
npm run build
npm run preview
```

## GitHub Pages 發佈

專案使用相對資源路徑，倉庫中的 `docs/` 是可直接託管的完整版本，不需要額外後端。

1. 將完整專案上傳到 GitHub 仓库的 `main` 分支。
2. 開啟 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 分支選擇 **main**，目錄選擇 **/docs**，按 **Save**。

更新遊戲後，執行 `npm run pages:build`，再把更新後的 `docs/` 一併提交即可。這個指令會重新建置並同步發佈目錄。

## 測試

```bash
npm test
```

引擎測試會驗證全部 15 天與 126 位入境者的文件、正確判定、錯誤判定及產生器一致性。

Playwright 測試包括完整戰役、顯示設定與拖放、對話盤問、指紋和拘留。執行前需啟動開發伺服器並安裝 Chromium：

```bash
npx playwright install chromium
node tests/visual-check.mjs
node tests/interaction-check.mjs
node tests/full-campaign.mjs
```

## 技術

React 18、Vite、原生 SVG 像素人物與頂視場景、原創像素背景、CSS 文件與實體桌面、Web Audio API、localStorage。遊戲執行時不需要外部 API、字型或圖片服務。
